# 🖥️ Aaryaman OS

A desktop-style portfolio experience built in the browser.

Instead of a traditional website, this project presents my work, projects, and information as an interactive operating system interface inspired by classic desktop environments.

---

## ✨ Features

* 🪟 Draggable, focus-based window system
* 🧠 OS-inspired UI/UX (taskbar, start menu, desktop icons)
* 📝 Notepad-style "About Me"
* 🌐 Browser-style project explorer
* 🎨 Creative section via MS Paint interface
* 📄 Resume viewer

---

## 🧱 Tech Stack

* **Next.js**
* **React**
* **TypeScript**
* **CSS / Tailwind (if used)**

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/aaryaman-os.git
cd aaryaman-os
npm install
npm run dev
```

---

## 🎯 Concept

This project explores the idea of:

> “What if a portfolio was an operating system?”

It focuses on interaction, familiarity, and making exploration feel natural rather than linear.
